# CCS 2214 – Data Structures and Algorithms Assignment

**Faculty:** Computing and Information Technology  
**Institution:** Multimedia University of Kenya  
**Language:** C

## Contents

- `question1_circular_queue.c` – Circular queue operations.
- `question4a_sum.c` – Recursive sum of the first N natural numbers.
- `question4b_factorial.c` – Recursive factorial.
- `question4c_fibonacci_term.c` – Find a Fibonacci term using recursion (F(0) = 0).
- `question4d_fibonacci_series.c` – Generate N Fibonacci terms using recursion.
- `question5_queue.c` – Enqueue and dequeue operations in a linear queue.
- `question6_sparse_matrix.c` – Sparse matrix representation using triplets.
- `question7_deque.c` – Front/rear insertion and deletion in a circular deque.

## Compile and run

Using GCC, compile a file with:

```bash
gcc question1_circular_queue.c -o question1
```

Run it with:

```bash
./question1
```

Replace the source filename and output name to test another question.

## Notes

Each C file is a separate program and has its own `main()` function.
Compile and run the files separately.
